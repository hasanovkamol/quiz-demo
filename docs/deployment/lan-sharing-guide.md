# Local Network (LAN) Deployment & Access Guide

Guide for exposing QuizMaster PRO to local Wi-Fi and Ethernet users.

---

## 🌐 LAN Access Setup

1. **Find LAN IP Address**:
   - Linux / macOS: `ifconfig` or `ip a` (e.g. `192.168.1.50`)
   - Windows: `ipconfig`
2. **Access from Mobile Devices / Laptops**:
   - Open browser and navigate to: `http://<YOUR-LAN-IP>` (e.g. `http://192.168.1.50`)
3. **Share Result Scorecard Link**:
   - Open any completed test result and click "Natijani Ulashish" to copy direct link: `http://<YOUR-LAN-IP>/result/<GUID>`
